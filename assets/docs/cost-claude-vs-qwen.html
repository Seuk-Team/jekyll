① 기술적

클라우드에서 Anthropic Claude 로 서빙 · Port 추상화로 교체 가능

서류 요약·평가·추천 3단 체인과 아르 도구 호출을 Claude 로 서빙(AWS EC2·Docker Compose). ChatBackend Port 로 프로바이더 교체 여지 확보. Colab QLoRA 로 학습한 chat(v9)·summary·interview 어댑터는 비용 절감 R&D 자산. GPU 실측(T4): STT 275ms/3s · ViT 75ms/crop.

② 경제적

사용량 요금은 캔드 응답·캐시로 절감 · 로컬은 규모 대안

기본·경계 질문 캔드 응답($0)과 프리픽스 캐시로 Claude 사용량 요금을 눌렀다. 09-11 Anthropic 실측(누적 $0.1479)이 기준선. 손익분기 그래프(축 ④)가 보여 주듯 규모가 커지면 로컬 GPU 가 저렴 — 그래서 Qwen 자체학습을 비용 절감 R&D 근거로 유지한다.

③ 전략적

고위험 채용 도메인은 최고 품질 + 사람 검토가 맞음 결정타

지원자 이력서·면접 발언·평가 근거의 판단 품질이 곧 서비스 품질. 채용은 고위험 도메인(사람 검토+고지 필수)이며 감정 인식 활용은 금지 — 그래서 표정·음성 신호는 판정에 넣지 않고, 판단 엔진은 품질·안정성이 검증된 Claude 로 간다. 이 축이 09-18 클라우드 + Claude 채택을 이끌었다.
