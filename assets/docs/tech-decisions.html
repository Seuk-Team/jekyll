  • 조회는 로그인만 하면 전부 허용 — 옛 "면접관은 배정된 지원서만" 규칙은 폐지됐다

4.코드 구조 — Bounded Context 넷 (ADR-0035)

09-12 폴더 재편의 출발점은 단순했다. models.py 하나를 71개 파일이 직접 참조하고 있어 무엇을 고쳐도 어디가 깨질지 몰랐다.

"하나의 중심"을 잡으려 했으나 Arda 에는 자연스러운 중심이 넷 있었다. 하나로 몰면 나머지 셋이 왜곡되므로 각자의 별로 뒀다.

5.지금의 제품을 만든 것은 개정이다

ADR 은 "확정"으로 끝나지 않는다. 오너가 개정 ADR 을 쓰면 바뀐다. 아래 넷이 모양을 가장 크게 바꿨다.

① 표정분석: 제외 → 도입 (ADR-0002 → 0029, 09-07)

원래 뺐던 근거는 강했다 — HireVue 가 2021년 중단(직무성과 예측 기여도 0.25% 미만), 얼굴 움직임으로 감정 추론이 어렵다는 학계 정리, 안면마비·자폐 지원자를 결함으로 점수화하는 차별 위험. 뒤집으면서 그 근거를 폐기하지 않고 문서에 남겼다. 지금의 타협은 표정·음성 수치가 담당자 화면에 보이되 점수 재료가 아니라는 것이다. AI 요약 문장도 측정된 숫자의 재서술만 허용하고, 수치에 없는 숫자나 사람을 단정하는 단어가 나오면 문장을 버리고 고정 틀로 대체한다.

② AI 판정: 추천까지만 → 단계는 AI, 최종만 사람 (ADR-0003 → 0034, 09-10)

"확정은 사람"이 최종 합불 한 곳으로 좁혀졌다. 서류는 아르가 100점으로 채점해 임계(기본 60) 이상이면 면접으로, 미만이면 탈락으로 옮긴다. 붙인 안전장치 셋:

  1. 이력에 changed_by=NULL(시스템)과 점수 사유가 남는다
  2. 불합격 메일은 즉시 안 나가고 마감 뒤 담당자가 일괄 발행한다(번복 여지)
  3. 사람이 한 번 손대면 그 지원자는 이후 자동 판정에서 빠진다 — 수동이 항상 이긴다

③ AWS: 8종 → 3종 (ADR-0031·0036)

예산 $400 과 10/27 종료가 전제였다. 핵심은 지우는 것이 아니라 스위치를 먼저 만든 것이다 — MAIL_DISPATCH · MAIL_TRANSPORT · QUEUE_BACKEND · S3_ENDPOINT_URL. S3 는 코드를 안 고치고 MinIO 로 갈 수 있다.

④ 실시간 화상면접: 제외 → 1:1 만 도입

기획 견적 "시그널링 + TURN + SFU 까지 1명의 4주"는 3인 이상이 전제였다. 둘이면 SFU 가 없어 두 끝점이 직접 붙는다. 전제를 다시 읽고 1:1 만 열었다. 3인 이상은 09-20 시연 뒤 집단 면접으로 다시 본다.
